2. **P1 · correctness — A referenced policy can get a dead detail link. Blocks close.** Generic link admission accepts objects referenced by a readable owned route. An HTTPRoute in install A can name a readable TrafficPolicy as a backendRef while the policy’s status assigns it only to install B. A’s `/refs` then advertises A’s policy detail URL, where `policyDetail` searches only A’s assigned and listed policies and returns 404. The existing policy-as-backend regression covers named denial for an in-install policy. Link creation and the destination need the same install-membership predicate. The page’s separate Namespace filter narrows rows, but the server still authorizes and checks every readable policy before applying it.
