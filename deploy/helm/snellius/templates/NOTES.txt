Snellius is installed. It is read-only.
{{- if eq (include "snellius.authMode" .) "local" }}
Snellius runs in local mode: it listens on the Pod's loopback only.
Anyone who can port-forward to it sees everything it reads (never Secrets),
which can be more than their own Kubernetes RBAC allows.

Open it with:
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "snellius.fullname" . }} 8080:80
then browse to http://localhost:8080
{{- else }}
Snellius runs in secure mode. The sign-in values arrive in a later release step.
{{- if .Values.httpRoute.enabled }}
It is exposed through an HTTPRoute.
{{- end }}
{{- end }}

Controller metrics are read directly from the controller pods on port 9092.
If a NetworkPolicy blocks that, the UI reports "signal unavailable" instead of green.
